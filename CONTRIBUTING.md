# Contributing

Thanks for considering a contribution.

## Before opening a pull request

1. Open an issue for substantial changes so the scope can be discussed.
2. Keep changes focused and preserve existing application behavior.
3. Never add API keys, `.env` files, private URLs or personal data.
4. Update documentation when routes, configuration or user-facing behavior changes.
5. Run `npm test`, `npm run lint` and `npm run build`.

## Development

Use Node.js 20 or newer. Follow the local setup in the README and configure your own AI provider key in `.env`.

## Pull requests

- Explain the problem and the approach.
- Include manual test steps and command output where relevant.
- Add or update tests for logic changes.
- Include screenshots for meaningful UI changes, with personal information removed.
